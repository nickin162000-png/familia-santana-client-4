# Familia Santana Client 4.0 (Forge 1.8.9)

- Right Shift: menu do client (abas HUD, Utilidades, Interface, Aparencia)
- Aba HUD > "Editar posicoes": arraste cada elemento do HUD para onde quiser
- C (segurando): zoom

Interface moderna: hotbar, barras de vida/fome/armadura/ar/XP, mira, tela inicial e menu de pausa.
Tudo pode ser desligado na aba Interface. Se algo der errado nos menus, edite
.minecraft/config/familiasantana.properties e coloque  Menus\ Modernos=false

Fonte propria: coloque font.ttf em src/main/resources/assets/familiasantana/fonts/

## Compilar pelo GitHub
Suba o conteudo desta pasta num repositorio. A aba Actions compila e o .jar
aparece em Artifacts (use o que NAO tem -sources no nome).
